# Encargo para la sesión que publicará

Publica esta landing de cumpleaños para mi mamá, María del Pilar Peralta Ramírez, en mi GitHub y activa GitHub Pages. Usa esta carpeta como raíz del proyecto. El sitio está terminado y es estático; no necesita compilación, instalación de paquetes ni backend.

1. Revisa `README.md` y abre `index.html` o inicia `npm start` para comprobar la página.
2. Comprueba la cuenta de GitHub autenticada y utiliza el repositorio que yo indique. Si aún no he indicado cuenta/repositorio o visibilidad, aclara únicamente esa elección antes de crearlo. No sustituyas archivos de otro proyecto.
3. Sube esta carpeta completa, incluidas `assets/` y `.nojekyll`, a la rama de publicación.
4. Configura GitHub Pages desde la raíz de esa rama. No es una app de React: no introduzcas un proceso de build ni rutas absolutas.
5. Verifica la URL pública: imágenes, estilos, selección de años, carta, cierre con Escape, cronología y botón de celebración, también en móvil.
6. Devuélveme el enlace del repositorio y la URL pública del homenaje.

Conserva la dedicatoria y el diseño. Los datos históricos están sintetizados del informe aportado y las limitaciones figuran en la cronología. No inventes edad, premios, estudios o cargo actual. No publiques el PDF de investigación ni archivos locales ajenos a esta carpeta.

El usuario preparó este encargo para pasarlo a otra sesión. Esta entrega local todavía no está publicada.
